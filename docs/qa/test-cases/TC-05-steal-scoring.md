# TC-05 — Steal, scoring, leftovers, multiplier

**Area:** Gameplay  
**Type:** Manual

## Setup

Board in play. Reveal at least one answer so the round pie is non-zero.

## Steps

1. Take three Family play X so steal is open. Miss the steal (or award the playing family if they already won the board).
2. **Award round** to A. Score A increases by round pie × multiplier. Audience scores match.
3. **Reveal leftovers**. Remaining tiles show; **score does not increase**.
4. Start a new round. Set multiplier **2x**, reveal answers, award. Points are doubled. Next round multiplier is **1x** again.

## Expected

Leftovers after award do not add points. Multiplier applies to the running round total only. Undo reverses the last reveal/strike/award when used immediately.
