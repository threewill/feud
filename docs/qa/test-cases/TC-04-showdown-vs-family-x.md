# TC-04 — Showdown X vs Family play X

**Area:** Gameplay  
**Type:** Manual

## Setup

Fresh board, question showing, strikes 0 / 3.

## Steps

1. Click **Showdown X (no strike)** several times. Audience gets an X overlay each time. Host strike count stays **0 / 3**. Family play X still reads **(1 of 3)**.
2. Click **Family play X (1 of 3)** once. Strikes become 1 / 3.
3. Click **Showdown X** again. Strikes stay 1 / 3.

## Expected

Showdown X never increments the 3-strike count. You can showdown-X back and forth without Undo. This is the split that the stale host screenshot does not show (UX-01).
